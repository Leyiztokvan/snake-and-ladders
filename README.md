# Snakes & Ladders
This is an implementation of the **Snakes & Ladders** game in **Java**.

### Testing 
The project focuses on **Test Driven Development (TDD)** principles.

In **Test Driven Development**:
- Tests are written in order to check whether a component behaves as expected in different use cases.
- Good tests cover as much code as possible and use diverse method's inputs
- Complex functions should have multiple tests in order to cover all paths
- Every edge case a function could have should be tested (ideally!)

The tests are written using `JUnit` and `Mockito`.

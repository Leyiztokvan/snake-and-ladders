# 🎲 Snakes & Ladders 
### ***(TDD Java Game Project)***

This is a clean and test-driven implementation of the **Snakes & Ladders** board game, built in **Java** using testing practices with **JUnit 5** and **Mockito**.

---

## Project Goals

- Practice **Test-Driven Development (TDD)**
- Build a **modular**, **object-oriented** game in Java
- Apply **automated unit testing** using industry-standard tools
- Demonstrate good software engineering practices for real-world scenarios

---

## Testing Approach

Testing is the main focus of this project.

✅ **JUnit 5** for unit and behavior tests  
✅ **Mockito** for mocking dependencies  
✅ **High code coverage** with multiple edge cases
